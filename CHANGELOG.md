# Changelog

All notable changes to this project will be documented in this file.

This project adheres to [Semantic Versioning](http://semver.org/spec/v2.0.0.html).

## 1.4.0 (Mon, 28 Sep 2026)

- Added support for data regions.
- Added support for configuring distinct server URLs for APM, analytics, traces, logs, and profiling.
- Added support for ignoring transaction URLs from dashboard and configuration.
- Added cgroup v2 support for container and Kubernetes pod detection.
- Added heap allocations and GC pause metrics to builtin metrics gatherer.
- Added error limits and performance improvements to aggregator.


## 1.3.0 (Mon, 9 Mar 2026)

- Added support for profiling.


## 1.1.0 (Tue, 6 May 2025)

- Added support for notify host.


## 1.0.1 (Fri, 1 Apr 2022)

- Fixed flush interval.


## 1.0.0 (Thu, 31 Mar 2022)

- General availability release of the Go agent.
